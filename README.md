# AI, Human Cognition and Knowledge Collapse

> Phase 1 working scaffold - not the final course deliverable.

This repository studies Daron Acemoglu, Dingwen Kong, and Asuman Ozdaglar, *AI, Human Cognition and Knowledge Collapse*, NBER Working Paper 34910. The course-designated reading copy is the authors' May 5, 2026 manuscript hosted by MIT.

Current working materials:

- [`analysis/paper_map.md`](analysis/paper_map.md): source audit, model map, static derivation, Observation 1, and open questions.
- [`paper/README.md`](paper/README.md): exact version and reproducibility record. The PDF itself is local and ignored by Git.
- [`prompts.md`](prompts.md): raw prompts from the kickoff phase; the phase response will be added later from the actual output.
- [`hand/README.md`](hand/README.md): candidate checks for a later handwritten derivation.
- [`extensions.md`](extensions.md): unresolved extension questions, not a final proposal.

The final one-page synthesis and five-minute Beamer deck have deliberately not been drafted in this phase.
